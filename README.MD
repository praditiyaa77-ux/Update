## 🌟 Tentang Bot Ini

**Patrick MD** adalah bot WhatsApp generasi baru yang dibangun menggunakan **ESM (ES Modules)**. Arsitektur ini membuat bot jauh lebih ringan, terstruktur, dan mudah dikembangkan. Dilengkapi dengan *handler* anti-crash, deteksi admin via LID (Linked ID) terbaru, serta dukungan *Passive Listener* untuk game interaktif berbasis reply.

> 💡 **Filosofi:** Tidak perlu library berat seperti `sharp` atau `wa-sticker-formatter`. Semua pemrosesan media (Stiker, Kompresi, Resize, HD) menggunakan **FFmpeg lokal** agar 100% berjalan lancar bahkan di hosting gratis!

## ⚙️ Persyaratan Sistem

Sebelum menjalankan bot, pastikan server/hosting Anda memiliki:

1. **Node.js** (Minimal versi 18.x / Direkomendasikan 20.x)
2. **FFmpeg** (Wajib diinstal untuk fitur stiker, thumbnail menu, dan kompresi media).
   - *Ubuntu/Debian*: `sudo apt install ffmpeg`
   - *Termux*: `pkg install ffmpeg`
